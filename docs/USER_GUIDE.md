# AI Gallery 使用说明

## 启动与关闭

日常使用请先运行生成的 Windows 安装包。安装完成后，从开始菜单打开 `AI Gallery`，不需要 Node.js、Rust、终端或启动脚本；也可以把快捷方式固定到桌面或任务栏。

开发调试时，才需要在仓库根目录运行：

```powershell
npm run desktop:dev
```

首次编译会比后续启动慢。关闭 AI Gallery 窗口即可退出；如果终端中的开发进程没有自动结束，再按 `Ctrl+C`。工作区数据保存在你创建或打开的工作区目录中，关闭应用不会删除媒体或数据库。

需要生成正式 Windows 安装包时运行：

```powershell
npm run desktop:build
```

原始安装包输出在 `src-tauri/target/release/bundle/nsis/`。交付时可将它复制到根目录的 `release/`，然后删除构建缓存。安装后直接使用快捷方式，只有开发或重新打包时才需要等待编译。

## 第一次使用

1. 启动后选择“创建工作区”，指定一个不存在的新目录；已有工作区使用“打开已有工作区”。
2. 在作品库中导入图片或 MP4。复制导入会把副本放进工作区；引用导入保留外部绝对路径，不移动源文件。
3. 为项目和作品编辑提示词、模型、平台、生成参数、分类、标签等信息。AI 识别和 AI 分类结果必须先在待审核页面确认，才会写入正式字段。
4. 删除操作先进入回收站；永久删除需要再次确认。重要修改或迁移前可在“设置”中创建备份。

## 搜索与选择性导出

作品页搜索框旁的“搜索范围”默认按作品名搜索，也可以切换为按提示词或备注搜索。提示词搜索涵盖作品的提示词字段；备注搜索只匹配备注内容。

导出单个或多个作品时，在作品页选择目标作品，然后使用“移入回收站”左侧的“导出所选”。导出项目时，先在项目页进入选择模式并勾选项目，再使用“新建项目”左侧的导出选项。

导出时可选择：

- **完整作品内容**：导出作品与项目数据、提示词、分类、备注及媒体文件副本。媒体不会被移动或删除。
- **仅提示词 JSON**：导出所选作品与项目的提示词，不包含媒体文件。JSON 使用缩进排版，便于阅读和编辑。

完整导出会在目标目录中创建独立导出文件夹，包含 JSON 清单和媒体副本；提示词导出会生成单独的 JSON 文件。导出目录应按其中的提示词和媒体内容进行隐私检查，再分享给他人。

## P1 功能入口

- “创作效率”：批量编辑、批量分类/AI、模型对比、智能集合、自定义字段、提示词版本和编辑历史。
- 作品库的“媒体完整性”：完全重复检查、视频关键帧或自定义封面、逐个修复丢失路径。Windows 安装包内置经过固定哈希校验的 FFmpeg 组件，用于导入视频时自动生成首帧封面和恢复默认封面；高级关键帧工具仍只运行你显式选择的 FFmpeg，不会从系统 `PATH` 自动查找或执行来源不明的程序。
