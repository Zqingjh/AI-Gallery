## 关键约束

- 启动不得扫描全库、全量哈希、生成全库缩略图或重建 FTS。
- 媒体列表必须数据库分页且单页不超过 50 条，只加载缩略图/封面。
- 后台缩略图/解析默认并发不超过 2，缓存必须有容量和清理策略。
- 10,000 条记录搜索/筛选目标小于 500 ms；性能回退超过 20% 不得合并。
- P0 不默认捆绑完整 FFmpeg、大型模型、浏览器内核或重复大型 UI 依赖。
